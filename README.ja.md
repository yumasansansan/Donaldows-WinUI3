# Donaldows Vista SP1 Hotfix 091016 for C#

往年のジョークソフト **「ドナルドウズ」** を，現代のWindows向けに **C#/.NETおよびWinUI 3で移植・再実装**するプロジェクトです．

> **English:** [README.md](README.md)

## ドナルドウズについて

「ドナルドウズ」は，2009年頃に制作されたジョークソフトです．オリジナル版は **HSP（Hot Soup Processor）** によって実装されています．

オリジナルのソースコードには，作者による以下の記述があります．

> 「改造しても構いませんが（例：エア本や兄貴のOSにするとか）」

この記述から，作者は第三者によるソースコードの改造を明示的に認めており，改造版の制作も想定していたことがうかがえます．

一方，確認できる範囲では，オリジナルのソースコードには MIT License や GNU GPL などの正式なオープンソースライセンスは明記されていません．

そのため，本プロジェクトではオリジナル作品が特定のOSSライセンスの下で公開されていたものとは扱っていません．

## このプロジェクトについて

本プロジェクトは，ドナルドウズの **C#/.NET・WinUI 3による非公式移植・再実装**です．

オリジナルのHSPソースコードをそのままC#へ変換したものではなく，本プロジェクトのC#コードは独自に実装しています．

一方で，移植プロジェクトであるため，オリジナル版の外観・動作・仕様は可能な限り忠実に再現しています．現代のWindows環境に合わせた変更や，軽微なバグ修正なども行っています．

## オリジナル由来のアセットについて

`Assets/` フォルダ内の大部分のファイルは，オリジナルのドナルドウズに由来するアセットです．

これらのオリジナル由来のアセットには，本リポジトリのC#ソースコードに適用されるMIT Licenseは適用されません．

したがって，このリポジトリのMIT Licenseによって，オリジナルの画像・音声その他のアセットについて追加の利用権が与えられるものではありません．

なお，`Assets/LockScreenLogo.scale-200.png` など，一部にはWinUI / Windowsアプリケーションのプロジェクトテンプレートに由来するファイルが含まれています．これらはオリジナルのドナルドウズ由来のアセットとは区別して扱います．
